# NYC Airbnb Pricing Analysis

A project analyzing Inside Airbnb's New York City listings data using SQL and Python.
The goal is to identify what drives pricing and derive pricing insights from a host or platform perspective.

## Data

- Source: Inside Airbnb (NYC listings scrape)
- data/raw/listings.csv: raw data, not modified
- data/processed/: cleaned data goes here

## Project Structure

- data/raw/ raw data, untouched
- data/processed/ cleaned data
- sql/ schema and analysis queries
- notebooks/ exploratory analysis, visualizations
- src/ reusable python functions
- outputs/figures/ saved chart images
